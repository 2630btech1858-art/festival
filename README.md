Indian Festivals & Culture

A simple, responsive website built to showcase the festivals and cultural heritage of India, created as part of a Mid-Semester Examination (MSE) assignment on Web Development and Cloud Foundation.

Objective

India celebrates hundreds of festivals every year, each carrying its own story, region, and tradition. The goal of this project is to build a small website that introduces visitors to a few of these festivals in a clear, visual way, while practicing the fundamentals of web development — HTML for structure, CSS for styling and responsiveness, and JavaScript for basic interactivity.

About the Website

The site opens with a short introduction to India's festival culture, followed by a Festivals section where each festival gets its own card — a photo, a title, and a short description explaining what it celebrates and how. A Gallery section collects a few more photos in one place, and a Contact section lets a visitor send a message through a simple form.

Six festivals are currently featured:

Diwali — the festival of lights, marked by diyas, home decorations, and sweets.
Holi — the festival of colours that welcomes spring.
Durga Puja — West Bengal's biggest festival, honouring Goddess Durga.
Onam — Kerala's harvest festival, known for flower rangoli and boat races.
Eid — celebrated by Muslims after the month of Ramadan, with prayers and feasts.
Christmas — marking the birth of Jesus Christ, celebrated on 25th December.

The design uses a warm maroon-and-orange colour scheme with a cream background, meant to echo the warmth of lamps, marigolds, and festival colours without being overly decorated.

Features
Clean, easy-to-read layout introducing major Indian festivals
Festival cards with an image, title, and short description, stacked for easy reading
A photo gallery section
Fully responsive design — works on desktop, tablet, and mobile
A mobile-friendly hamburger menu for smaller screens
A contact form with basic JavaScript validation (checks that all fields are filled before submitting)
Technologies Used
Technology	Purpose
HTML5	Page structure and content
CSS3	Styling, layout, and responsiveness (Flexbox + media queries)
JavaScript (Vanilla)	Mobile menu toggle and form validation

No frameworks or libraries were used — the entire site is built with plain HTML, CSS, and JavaScript.
